# TubeLite

বিজ্ঞাপনমুক্ত YouTube ক্লায়েন্ট — ব্যাকগ্রাউন্ড প্লেব্যাক, ডাউনলোড, ডার্ক মোড, অটো-প্লে, PiP সহ।

NewPipeExtractor ব্যবহার করে YouTube-এর সরাসরি ওয়েব এন্ডপয়েন্ট থেকে স্ট্রিম বের করা হয় —
অফিসিয়াল Data API বা বিজ্ঞাপনযুক্ত ক্লায়েন্ট ব্যবহার করা হয় না।

## মোবাইল থেকে GitHub-এ আপলোড ও APK বিল্ড (কম্পিউটার ছাড়াই)

1. **রিপো তৈরি করুন**: GitHub অ্যাপ বা মোবাইল ব্রাউজারে github.com-এ গিয়ে
   "New repository" → নাম দিন `TubeLite` → Create।

2. **ফাইলগুলো আপলোড করুন**:
   - GitHub ওয়েবসাইটে রিপোর মধ্যে "Add file → Upload files" চাপুন
   - এই পুরো ফোল্ডারের সব ফাইল/সাবফোল্ডার (zip থেকে বের করে) ড্র্যাগ করে দিন,
     অথবা zip ফাইলটাই আপলোড করে GitHub-এর মধ্যে থাকা কোনো "extract" অপশন না থাকলে
     মোবাইলে একটা ফাইল ম্যানেজার/zip এক্সট্র্যাক্টর অ্যাপ (যেমন Files by Google, ZArchiver)
     দিয়ে আগে এক্সট্র্যাক্ট করে নিন, তারপর ফোল্ডার স্ট্রাকচার বজায় রেখে আপলোড করুন
   - "Commit changes" চাপুন

3. **অটো বিল্ড শুরু হবে**: `.github/workflows/build-apk.yml` ফাইলটি থাকার কারণে,
   কমিট করার সাথে সাথেই GitHub Actions অটোমেটিক্যালি APK বিল্ড করা শুরু করবে।
   রিপোর "Actions" ট্যাবে গিয়ে প্রগ্রেস দেখতে পারবেন (৩-৫ মিনিট সময় লাগবে)।

4. **APK ডাউনলোড করুন**: বিল্ড শেষ হলে (সবুজ ✓ চিহ্ন), সেই workflow run-এর পেজে নিচে
   "Artifacts" সেকশনে `TubeLite-debug-apk` নামে একটা zip পাবেন — ডাউনলোড করুন,
   এক্সট্র্যাক্ট করলে `app-debug.apk` পাবেন।

5. **মোবাইলে ইনস্টল**: APK ফাইলে ট্যাপ করুন। প্রথমবার Android
   "Install unknown apps" পারমিশন চাইবে — Settings থেকে অনুমতি দিয়ে ইনস্টল করুন।

## গুরুত্বপূর্ণ নোট

- এই প্রজেক্টটি YouTube-এর Terms of Service-এর গ্রে-এরিয়াতে কাজ করে (NewPipe/LibreTube-এর
  মতোই)। এটা ব্যক্তিগত ব্যবহারের জন্য, Play Store-এ প্রকাশযোগ্য নয়।
- এটি একটি **স্টার্টার স্ক্যাফোল্ড** — প্রথমবার বিল্ডে ছোটখাটো ডিপেন্ডেন্সি ভার্সন
  সমস্যা হতে পারে (NewPipeExtractor বা Media3-এর নতুন ভার্সন রিলিজ হলে)। Actions লগে
  এরর দেখলে আমাকে জানালে ঠিক করে দেব।
- ভবিষ্যতে ফিচার যোগ করতে চাইলে (কমেন্ট, চ্যানেল পেজ, প্লেলিস্ট, রেজোলিউশন সিলেকশন,
  কোয়ালিটি অনুযায়ী কম ডেটা মোড ইত্যাদি) — বলুন, কোড এক্সটেন্ড করে দেব।
